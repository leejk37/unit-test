# 청평초 단원평가 · 완전학습

4학년 교과 단원평가입니다. 학생은 학교 구글 계정(@cpe.es.kr)으로 로그인해 교과와 단원을 고르고, 단원마다 개념별로 80%에 못 미치면 보충 학습 뒤 재도전합니다.

- `index.html` 학생 화면: 교과 → 단원 목록 → 단원 평가 (주소 끝 `#단원ID`로 단원 바로 열기)
- `teacher.html` 교사 화면: 단원을 골라 학급 현황, 문항 분석, 서술형 확인
- `config.js` 서버 주소와 로그인 클라이언트 ID
- `api.js` 구글 로그인과 서버 호출

단원 목록은 구글 시트의 '단원' 시트에서, 문항은 Apps Script의 단원 파일(`Unit_<단원ID>.gs`)에서 관리합니다. 정답과 기록은 이 저장소에 없습니다.
