# 여러 가지 기체 · 온라인 평가와 완전학습

4학년 2학기 과학 3단원 「여러 가지 기체」 온라인 평가입니다. 학생이 학교 구글 계정(@cpe.es.kr)으로 로그인해 평가를 보고, 개념별로 80%에 못 미치면 보충 학습 뒤 재도전합니다.

- `index.html` 학생 화면
- `teacher.html` 교사 화면 (구글 시트 '교사' 시트에 등록된 계정만)
- `config.js` 서버 주소와 로그인 클라이언트 ID
- `api.js` 구글 로그인과 서버 호출

채점, 정답, 기록은 모두 구글 앱스스크립트(Code.gs)와 구글 시트에 있습니다. 이 저장소에는 정답이 들어 있지 않습니다.
